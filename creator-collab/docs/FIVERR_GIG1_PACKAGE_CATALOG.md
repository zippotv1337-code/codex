## Hard scope limits

- A revision changes the agreed implementation; it does not add a new workflow,
  integration, dashboard or major feature.
- Paid tools, licenses, API usage, cloud hosting and third-party subscriptions
  are excluded unless separately scoped and approved.
- The client provides lawful access and verifies rights to supplied data,
  content, brands and accounts.
- Platform/API feasibility is confirmed before implementation. Unsupported or
  prohibited automation is excluded.
- No fake engagement, spam, policy circumvention or performance guarantees.

## Custom Offers

Use a custom offer from **900–1,500 USD+** for more than three workflows, more
than three integrations, multiple dashboards, unusual/custom API work, longer
support or materially expanded scope. Final price and delivery time follow a
written scope check; no external paid commitment is made automatically.
