# Fiverr Gig 1 — Customer Intake

Do not request passwords, OTPs, payment data or unnecessary personal data.
Use secure invitations/OAuth and minimum permissions when access is needed.

## Required questions

1. What business result should this automation produce?
2. Which tools, platforms or accounts are involved?
3. What currently happens manually, step by step?
4. What should trigger the workflow and what should happen afterward?
5. Which package are you ordering, and which exact workflows and integrations
   should it cover?
6. What would count as a successful delivery and acceptance test?

## Optional scope questions

7. Do you need reporting or a dashboard? If yes, which metrics and who will use
   it?
8. Which safe access method can you provide: team invitation, OAuth or a
   platform-specific credential with minimum permissions?
9. Are any paid third-party services required or already licensed?
10. Do you have brand colors, a logo, sample output or existing documentation
    that you are authorized to share?

## Internal acceptance check

- Scope: `ACCEPT / CLARIFY / CUSTOM_OFFER / DECLINE`
- Official interface: `API / CONNECTOR / WEBHOOK / GUI_FALLBACK / MANUAL`
- Access: `MINIMUM_PERMISSIONS / NEEDS_OWNER_ACTION / BLOCKED`
- Paid dependencies: `NONE / DISCLOSED_AND_APPROVED / BLOCKED`
- Safety/compliance: `PASS / NEEDS_REVIEW / DECLINE`
- Verification plan: `DEFINED / NEEDS_CLARIFICATION`
